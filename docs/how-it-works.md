# ไม้นี้คำนวณยังไง

เว็บคิดจาก **Margin ที่ใส่แต่ละไม้** ไม่ได้คิดจากทุนทั้งบัญชี

```
Margin (ที่กรอก) × Leverage = ขนาดโพซิชัน
→ ถ้าโดน Stop Loss จะเสียเท่าไหร่ = ผลลัพธ์
```

---

## 1. Leverage และราคา Liquidation

- **Leverage** — ค่าที่คุณตั้ง ใช้คิดขนาดโพซิชัน
- **Liquidation** — **กรอกจากหน้า Exchange เท่านั้น** เว็บไม่คำนวณให้ เพราะ Exchange คิด Liq ตาม tier ของ MMR และขนาดโพซิชัน สูตรประมาณจึงไม่ตรง

เว็บใช้ราคา Liquidation เพื่อ (1) เช็กว่า Stop Loss อยู่ก่อน Liq และ (2) วาดเส้นราคา — ส่วน "สไตล์" (กรณี R:R = กำหนดเอง) ใช้ Liq เป็นจุดอ้างอิงวาง SL

## 2. Stop Loss

SL วางไว้ **ก่อนถึง Liquidation** เสมอ ตามสไตล์ที่เลือก

| สไตล์ | SL อยู่ที่ % ของระยะ Entry → Liq |
|---|---|
| ปลอดภัย | 40% |
| สมดุล | 60% |
| ดุดัน | 80% |

## 3. ขนาดโพซิชันและเงินที่เสีย

```
ขนาดโพซิชัน    = Margin × Leverage
จำนวนเหรียญ    = ขนาดโพซิชัน ÷ Entry
ถ้าโดน SL เสีย = จำนวนเหรียญ × |Entry − SL| + 0.05% × จำนวนเหรียญ × (Entry + SL)
```

ค่าธรรมเนียม 0.05% ต่อฝั่ง (เข้า + ออก)

## ตัวอย่าง (ค่าเริ่มต้น)

LONG · Entry 60,000 · Leverage 10x · Margin 100 USDT · สไตล์สมดุล · 3 TP / 3R

| ขั้น | คำนวณ | ผล |
|---|---|---|
| Liquidation | กรอกจาก Exchange | 54,300 |
| Stop Loss | 60,000 − 5,700 × 60% | **56,580** (ราคาวิ่ง 5.70%) |
| ขนาดโพซิชัน | 100 × 10 | **1,000 USDT** |
| จำนวนเหรียญ | 1,000 ÷ 60,000 | 0.016667 |
| ถ้าโดน SL เสีย | 0.016667 × 3,420 + ค่าธรรมเนียม | **57.97 USDT (58% ของ Margin)** |
| กำไรรวมถ้าถึงทุก TP | | +95.85 USDT · R:R 1 : 1.65 |

## เปลี่ยนค่าไหน อะไรเปลี่ยน

| เปลี่ยน | ผลที่ได้ |
|---|---|
| **Margin** | ขนาดโพซิชัน, จำนวนเหรียญ, เงินที่เสีย, กำไร ขยายตามสัดส่วนตรง ๆ — ราคา SL / TP / Liq และ R:R **ไม่เปลี่ยน** |
| **Leverage** | ขนาดโพซิชัน (Margin × Leverage) — ราคา Liquidation ต้องกรอกใหม่จาก Exchange |
| **สไตล์** | SL ใกล้ / ไกล Liq — สไตล์ดุ เสียมากขึ้นถ้าโดน SL แต่ราคามีที่แกว่งมากกว่า |
| **จำนวนเป้า TP / ระยะ TP** | ราคา TP, สัดส่วนปิด, กำไรรวม และ R:R |

---

> **หมายเหตุ:** ราคา Liquidation ต้องกรอกตามที่ Exchange แสดง — ถ้าเปลี่ยน Leverage หรือ Margin ให้ดูราคา Liq ใหม่จาก Exchange แล้วกรอกอีกครั้ง
