# Futures Trade Calculator

เว็บคำนวณ Position Size, Margin, Liquidation, PnL และ Risk:Reward สำหรับ USDT-M Futures — ไฟล์เดียว (`index.html`) ไม่ต้อง build

## Deploy บน GitHub Pages
1. Push repo ขึ้น GitHub
2. ไปที่ **Settings → Pages**
3. Source: **Deploy from a branch** → Branch `main` / `(root)` → Save
4. เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`
